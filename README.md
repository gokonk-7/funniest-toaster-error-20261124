The funniest error message a kitchen toaster would show its owner — one line, at most 120 characters, written for make.fun's "The Funniest Toaster Error Message" bounty ($2, winner takes all). The entry is a deadpan appliance scolding its owner with an error code and a specific, user-caused fault, instead of a reheated toast pun.

The line (74 characters):

> ERROR E-27: Bread inserted upside down. I am not angry. I am disappointed.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), where the gate scorer checks it is UTF-8 text of 1 to 120 characters, not only white space. Requires Node 22.18 or later.
